    Lokale Seiten

    Mit GitHub Copilot bearbeiten
    
        
    Öffnet den Arbeitsordner als Projekt in VS Code oder IntelliJ. Anweisungen für Copilot, Prompts wie /seite-erweitern und Aufgaben zum Prüfen und Zurückschreiben sind dort eingerichtet.
    
      
    
      
    
        
        
        
      
    
    
    
    
    
    
    
      
    Noch keine Seiten im Arbeitsordner.
    
      
    Exportiere eine Seite oder lege eine neue an – sie erscheint dann hier.

    Personal Access Token erstellen
    
        
      
          
    1. In Confluence oben rechts auf dein Profilbild klicken und Einstellungen wählen.
      2. 
          
    2. Persönliche Zugriffstokens öffnen und Token erstellen wählen.
      3. 
          
    3. Namen vergeben, Ablaufdatum wählen und den Token kopieren. Er wird nur einmal angezeigt.
      4. 
          
    4. Token hier einfügen und speichern.
      5. 
        
    
        
    Admin-Rechte braucht es nicht; der Token hat dieselben Rechte wie dein Benutzer. Hat der Admin Tokens deaktiviert, Benutzername und Passwort verwenden.

    Zurückschreiben
    
      
    
    
    
    
    
  
    
  
    
    
    
      
      
    
    
    
    
      
      
      
    Leer lassen, um den Titel nicht zu ändern.
    
    
    
    
    
      
      
    
    
    
    
      
    Versionskonflikt. Die Seite wurde auf dem Server seit deinem Export geändert. Zurückschreiben würde diese fremden Änderungen überschreiben.
    
      
    
      
    Empfohlen: «Unterschiede anzeigen», dann «Server-Fassung holen». Die aktuelle Fassung vom Server ersetzt deine lokale; deine Fassung bleibt als page.xhtml.bak im Ordner. Übernimm deine Änderungen danach mit «Bearbeiten» (oder in Claude Desktop) und schreibe erneut zurück.
